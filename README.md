# Connectome

<img src="img/connectome_logo.png">

Add **Connectome** to your project:

```
npm install connectome
```

Connectome establishes a backbone for [DMT SYSTEM](https://dmt-system.com) and may be used elsewhere as well.

⚠️ This is Connectome 0.2 which is a proof of concept. It works perfectly on LAN as a part of DMT SYSTEM and has lower security assumptions. For LAN is more than adequate. Connectome 2.0 is an entirely redesigned "neural backbone for dmt processes" with proper security based on Noise protocol and public relaying option. Higher versions of Connectome are not public yet, see DMT SYSTEM website. This project possibly does not make great sense as a library to include elsewhere, it is tailor-made for DMT SYSTEM.
